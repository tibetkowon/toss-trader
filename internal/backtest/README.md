# 백테스트 데이터

수집은 저장소 루트에서 실행합니다.

```sh
go run ./cmd/backtest fetch KR
go run ./cmd/backtest fetch US
```

인증은 환경변수 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`을 사용합니다.
시작할 때 VM 토큰 무효화 경고를 출력합니다. 계좌 조회는 하지 않습니다.
`BACKTEST_MAX_PAGES`는 이번 실행에서 종목당 추가 수집할 분봉 페이지 수입니다(기본 400, 페이지당 200봉).

캐시는 gitignore에 등록된 `.cache/backtest/<시장>/<종목>/`에 저장합니다.
유니버스는 `<시장>/_universe/1mo.json`에 보관하며, 최초 수집한 월간 거래대금 상위 100종목을 재사용합니다.
일봉(최대 200개), 종목정보, 유의사항도 이미 저장되어 있으면 다시 요청하지 않습니다.
분봉은 가장 오래된 캐시 시각을 첫 before로 사용하고, 이후 API의 nextBefore를 그대로 전달합니다.
25페이지마다, 정상 종료 및 조회 오류 시 저장합니다. 강제 종료 시 마지막 저장 이후 페이지는 다시 수집할 수 있습니다.
끝까지 수집한 종목은 완료 표시를 저장하여 재요청하지 않습니다. 최신 데이터 갱신이 필요하면 별도 캐시 디렉터리로 새로 수집해야 합니다.

`NewHistSource(Cache{Dir: ...}, "KR" 또는 "US")`는 캐시만 읽습니다.
누락되거나 손상된 파일은 오류로 반환하며 네트워크로 대체하지 않습니다.
`SetClock(t)` 호출 후 캔들과 랭킹을 조회합니다. 초기 시계는 영시각이므로 과거 데이터도 반환하지 않습니다.
분봉은 시각이 clock보다 작은 정규장 봉만 반환합니다(개장 포함, 폐장 제외).
일봉 거래일은 라이브 스크리너와 동일하게 원문 timestamp의 날짜를 사용하며, 시장 현지 clock 날짜 이전만 반환합니다.
반환 순서는 최신순이며 next 토큰은 다음 호출의 before로 그대로 전달합니다.
HistSource와 Gate의 시계 설정은 단일 재생 루프에서 사용하며 동시 사용을 지원하지 않습니다.

한계: 유니버스는 수집 시점 기준이므로 생존편향이 있습니다. 종목정보와 유의사항도 과거 값이 아닌 수집 시점 값입니다.
랭킹은 일봉 OHLC 평균 또는 정규장 분봉 종가와 거래량으로 재구성하므로 실제 API 랭킹과 다를 수 있습니다.
종목정보의 레버리지 판정에 필요한 Raw는 별도로 함께 보존합니다.
정규장은 고정 시간대(KR 09:00–15:30, US 09:30–16:00, 미국 서머타임 반영)를 사용하며 조기 폐장 일정은 반영하지 않습니다.

인자 없는 `go run ./cmd/backtest`는 기존 워치리스트 백테스트를 실행합니다.
